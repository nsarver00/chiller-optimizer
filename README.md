This project is a Streamlit-based Chiller Plant Optimization tool that models building cooling loads using user made room parameters and real weather data from the Open-Meteo API. It evaluates different chiller combinations to minimize energy consumption while meeting cooling loads, incorporating IPLV efficiency curves and redundancy checks. The app also simulates economizer operation by comparing outdoor and indoor enthalpy conditions to estimate runtime, energy savings, and payback period. Users can explore cost impacts, system efficiency, and performance across different locations and time ranges.
