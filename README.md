This project is a Python-based HVAC chiller plant optimization tool that evaluates all possible chiller combinations to meet a building’s cooling load. It selects the group with the lowest total power consumption while checking demand is satisfied. Calculates building load given user input for room information including suppluy and return temps, cfm, and square footage. Chiller data is preloaded into the app, and outputs include 2 csv files with chiller cost and power usage data, along with room cooling loads. The model shows basic optimization, energy modeling, and HVAC system design logic.
